# Rep5x - Ender 3 Pro adaptation

Follow the main [assembly guide](../../assembly-instructions-universal.md) with these Ender 3 Pro specific differences.

## What's different

The Ender 3 Pro adaptation is relatively straightforward compared to other Ender 3 variants. The only modification required is relocating the Z endstop to home to Z max instead of Z min.
