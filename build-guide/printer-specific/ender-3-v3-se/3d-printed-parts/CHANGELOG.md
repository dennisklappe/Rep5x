# Ender 3 V3 SE - 3D printed parts changelog

Version history and changes for Ender 3 V3 SE specific 3D printed components.

---

## Version 1.1.1 (January 2026)

### carriage-mount v1.1.1
- **Updated**: Widened yaw stepper bolt holes to accommodate M3 washers (7mm OD)
- **Fixed**: Corrected spacing between locking holes to properly align with stepper mounting holes for improved tensioning
- **Reason**: Previous version caused deformation at yaw stepper connection due to insufficient clearance; locking holes were misaligned with stepper holes preventing proper tensioning
- **Requires**: 4x M3 washers (7mm outer diameter) - added to BOM
- **Compatibility**: Direct replacement for v1.1.0. Use with slip-ring-holder v1.1.1 from universal parts
- **Future**: Could benefit from a dedicated tensioning system in a future revision
