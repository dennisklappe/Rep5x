Direction check

Verify C and B axis motors rotate in the correct direction. Only needed once after initial build or motor changes.

C-axis (rotation)

○

Test if the build plate rotates counter-clockwise when viewed from above.

Testing...

C-axis direction is inverted

Fix with one of these options:

Option 1: Change firmware

In Configuration.h, change INVERT_I_DIR from false to true (or vice versa), then recompile and upload.

Option 2: Swap motor wires

Power off, then swap the two wires within one coil pair on the C-axis motor connector (e.g., swap pins 1&2 or pins 3&4).

After fixing, restart the setup wizard to test again.

Z-axis calibration

Set the Z=0 position (nozzle touching bed) using the paper test method

Paper test method

  1. Place a piece of paper on the bed under the nozzle
  2. Lower Z slowly until paper has slight resistance when moved
  3. Paper should slide with friction, not be stuck
  4. Click "Confirm Z0" when the gap feels right
Z0 position recorded: --mm from Z max

Z-axis control

0.0
mm (height from bed)
Caution:
  • Move slowly when close to the bed
  • Nozzle should be cold for this test
  • If nozzle hits bed, stop and raise Z immediately
Keyboard controls:
  • PgUp PgDn Move Z up/down
  • 1-4 Select step size
  • Enter Confirm position
  • Space Emergency stop
Step: 0.1mm
