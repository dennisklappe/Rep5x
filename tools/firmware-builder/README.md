# Rep5x - Firmware builder

A web-based tool to configure and build custom Marlin firmware for your Rep5x 5-axis printer, with cloud compilation.

**Live tool:** https://tools.rep5x.com/firmware-builder/

## Features

- **Visual configuration wizard**: Step-by-step setup for all firmware settings
- **Cloud compilation**: Build firmware directly in your browser, no local toolchain needed
- **Save/load configurations**: Export your config as JSON, reload it later to make changes

## Quick start

1. Go to https://tools.rep5x.com/firmware-builder/
2. Follow the wizard to configure your printer settings
3. Click **"Build firmware.bin"** on the final step
4. Copy `firmware.bin` to an SD card and flash your printer

For detailed instructions, troubleshooting, and manual build options, see the [firmware guide](../../build-guide/universal-parts/firmware/).
